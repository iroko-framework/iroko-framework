# Iroko Framework - Public Data

This directory contains **minimal public data** from the Iroko Historical Society archive.

## What's Included

These files contain ONLY:
- Scientific names (Darwin Core taxonomy)
- Vernacular names (Yorùbá, Lucumí, Spanish, English, etc.)
- Basic botanical classification (family, genus)
- Tradition affiliation (which traditions use this plant)

## What's NOT Included

The following information is **NOT published** here and requires authentication at https://iroko.org:

- Ritual uses and ceremonial applications
- Medicinal uses and healing applications
- Entity associations (which òrìṣà/lwa/mpungu)
- Harvest protocols and timing
- Preparation methods and quantities
- Ceremonial sequences
- Invocations and prayers
- All operational/practitioner knowledge

## Access Tiers

Iroko Historical Society uses a tiered access model:

| Level | Access To |
|-------|-----------|
| **Public** | Scientific names, vernacular names (this dataset) |
| **Community** | General ritual context, basic harvest info |
| **Initiated** | Detailed preparation, quantities, combinations |
| **Practitioner** | Ceremonial sequences, verification protocols |

For access beyond public data, visit https://iroko.org and request verification.

## Using This Vocabulary

Other institutions can use the Iroko Framework vocabulary with their own data and make different choices about what to publish publicly.

See: https://iroko-framework.github.io/iroko-framework/docs/REUSE.md
