About the Iroko Framework

The Iroko Framework provides controlled vocabularies and access governance mechanisms for documenting sacred knowledge in Afro-Atlantic traditions. It supports postcustodial archival approaches where communities maintain authority over their knowledge while enabling semantic interoperability.

Key Features

  • Field-Level Access Control: Granular permissions from public-unrestricted to initiated-elder
  • Contested Knowledge Support: Multiple lineage perspectives can coexist without requiring resolution
  • Provenance Tracking: Oral transmission chains, fieldwork context, epistemic transparency
  • Semantic Interoperability: Integrates with Darwin Core, SKOS, Dublin Core, PROV-O
